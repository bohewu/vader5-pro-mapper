# Vader5 Pro Mapper

[English](README.md)

飛智 **黑武士 5 Pro / Vader 5 Pro** 的 Windows 改鍵與輸入測試工具，使用 PowerShell、C# 和 **Windows Forms**。

可設定板載映射與原生連發，對照實體原始訊號與遊戲收到的 XInput 輸出。設定存進手把後，平常不用開工具；只有改鍵或測試時需要。本工具不修改或刷寫韌體。

## 相容範圍

| 項目 | 狀態 |
| --- | --- |
| 系統 | 64 位元 Windows、64 位元 PowerShell 7.2 以上 |
| 手把 | 標準版黑武士 5 Pro，USB `37D7:2401`、型號代碼 130 |
| 韌體 | 僅驗證 **7.1.5.4**，其他版本停止操作 |
| 配置格式 | **3.2**，840 位元組 |
| 連線 | 已測試 USB 有線與 USB 2.4 GHz 接收器 |
| 藍牙／Switch 模式 | 此工具不支援 |
| 配置 | 編輯目前啟用的 PC 配置 1～4 |

目前使用**一台 PC、一支手把**實測。接收器已驗證讀取、改鍵寫入、完整讀回、原配置逐位元還原，以及原始／XInput 監測；有線已驗證拔插後保留設定與原生連發。不代表所有 PC、韌體或接收器版本都已驗證。

**巨集實測：**USB 有線及 USB 2.4 GHz 接收器，M3 觸發 A/B 序列，單次、按住重複及切換重複三種模式皆收到預期輸出。兩種連線均通過映射／巨集寫入、完整讀回及原配置逐位元還原；接收器測試另確認每次停止後至少一秒沒有額外輸出。結果限於上述 PC 與已測手把、接收器，不代表所有裝置與時間組合。

板載映射預期會跟著手把移到其他 PC；若要在另一台執行編輯器，仍需要下列執行環境、DLL 和相容連線模式。驅動、其他改鍵程式及同時連接多支手把，都可能影響偵測及測試結果。目前沒有第二台 PC 的實測結果。

## 功能

- 一般按鍵、C/Z、M1～M4、LM/RM 的遊戲按鍵映射。
- 可恢復支援按鍵的預設值，或停用其遊戲輸出；L3/R3 下壓也可自行調整。
- 手把原生連發：關閉、按住連發、按一下切換；每秒 1～20 次。
- 板載巨集：設定觸發鍵、遊戲按鍵的按下／放開與延遲，以及單次、按住重複或切換重複。
- 明確的 Turbo 總開關，作用範圍為所有配置。
- 分別顯示原始實體按鍵和映射後的 XInput 輸出，包含四軸與 LT/RT。
- 寫入前備份、完整讀回比較；失敗時嘗試還原並回報結果。
- 保留未編輯的按鍵及其他欄位；啟動與重新讀取不套用預設映射。
- 顯示未儲存狀態，重新讀取或關閉前確認是否捨棄修改。

擴充鍵原生連發已測得設定 15 Hz 時約每秒 14.95 次，只代表已測組合，不代表所有按鍵及播放模式均已實測。

## 啟動前準備

1. 安裝 64 位元 PowerShell 7.2 以上，並讓 `pwsh.exe` 位於 `PATH`。
2. 保留飛智空間站的安裝；工具使用其現有的 `hidapi.dll`，儲存庫不附帶廠商 DLL。
3. 用 USB 資料線或 USB 2.4 GHz 接收器連接一支手把，保持手把開機。
4. 完整退出飛智空間站，包含系統匣程式。
5. 用**系統管理員 PowerShell** 暫停背景服務，避免配置切換或傳輸干擾：

   ```powershell
   Stop-Service -Name 'Flydigi Space Station Service'
   ```

   服務執行時工具會拒絕直接操作。本工具不更改服務的啟動類型；重新啟動後可能需要再停止服務。要恢復空間站時，先關閉本工具，再啟動該服務。

6. 雙擊 `Launch.cmd`／`開啟改鍵工具.cmd`，或執行：

   ```powershell
   pwsh -NoProfile -STA -File .\VaderMappings.ps1
   ```

DLL 預設從空間站的標準安裝目錄載入。若安裝於其他位置，可用環境變數 `VADER_HIDAPI_PATH` 指定現有的 `hidapi.dll`；DLL 與 PowerShell 的架構必須相符。

PowerShell 安裝位置若不在 PATH，可在工具旁建立不納入 Git 的 `runtime.local.cmd`：

```bat
set "VADER_PWSH=完整的-pwsh.exe-路徑"
```

## 改鍵與連發

1. 選擇輸出，也可選「預設」、「停用遊戲輸出」或「保留目前設定」。
2. 選擇「關閉」、「按住連發」或「按一下切換」，設定每秒次數。
3. 要使用連發時，確認 Turbo 總開關已勾選；此開關影響所有配置。
4. 按「儲存到手把」套用目前配置的修改。

例如 C → A 是一般改鍵；M1 → RB、按住連發、15 次／秒並開啟 Turbo 總開關，則是按住 M1 連發 RB。沒有任何按鍵被強制映射或固定停用。

「停用遊戲輸出」使用韌體的非遊戲按鍵目標，**不會清除既有空間站鍵盤／滑鼠綁定**；原先綁定仍可能產生鍵鼠事件。「保留目前設定」可保留既有巨集或其他目標。巨集請至「巨集」頁編輯；目前不提供鍵盤／滑鼠綁定編輯。

實體 Turbo 鍵的快捷操作與本工具直接寫入的連發設定是不同入口。擴充鍵使用連發時，請先指定一般遊戲按鍵輸出。

只有按「儲存到手把」才套用；每次修改目前配置，Turbo 總開關則影響所有配置。未編輯的按鍵與其他設定會保留。備份位於工具旁的 `backups/`，滑鼠停在儲存狀態文字上可查看備份位置。

## 板載巨集

1. 切換至「巨集」頁，讀取目前配置；讀取不會寫入。
2. 按「新增巨集」，或選擇既有巨集。
3. 設定觸發鍵、名稱、播放模式及重複間隔。儲存後，該觸發鍵會改為播放巨集，取代目前的遊戲按鍵映射。
4. 逐列編輯「距前一步等待 ms」、「遊戲按鍵」和「動作」。等待時間在**該步驟之前**，第一步可設 0；支援同時按住多鍵。
5. 「加入 A 按放」新增一組可編輯的按下／放開步驟，可改成其他遊戲按鍵，並刪除或上下移動。
6. 按「儲存巨集到手把」。工具會一起備份映射與巨集、寫入、重新載入配置，並完整讀回比較；失敗時嘗試還原兩者並回報結果。

例如：`0 ms A 按下`、`100 ms A 放開`、`200 ms B 按下`、`100 ms B 放開`，會依序點按 A、B，從開始到結束共 400 ms。

播放模式包含「單次」、「按住重複」及「切換重複」（再按一次停止）。「重複間隔 ms」是每次播放之間的等待，與步驟延遲、Turbo 總開關無關。

每個配置最多 **10 組**，共用 **1632 位元組**；每組佔 32 位元組，另加每步 4 位元組。單組最多 256 步，時間軸上限 65535 ms。名稱最多 **20 個 UTF-8 位元組**，中文字通常每字佔 3 個。工具會拒絕重複觸發鍵、不支援的輸出、容量不足、時間溢位與結束時仍有按鍵未放開的序列。

刪除巨集時，只有仍指向該巨集的觸發鍵會恢復韌體預設；後來另設的一般映射會保留。未編輯的巨集記錄及其他映射欄位原樣保留。切換兩個編輯頁前，請先儲存或重新讀取以捨棄草稿；「按鍵測試」顯示目前已存入手把的設定。

巨集存入手把後不用常駐程式。目前支援一般遊戲按鍵輸出，沒有鍵盤／滑鼠事件、類比搖桿動作、錄製及匯入／匯出。巨集與原生連發是各自獨立的功能。

## 按鍵測試

- **原始實體訊號：**包含 C/Z/M1～M4 等擴充鍵，尚未套用遊戲按鍵映射。
- **遊戲收到的輸出：**第一個已連接的 XInput 槽位，已套用手把映射與連發。

改鍵、停用或連發時，上下兩區出現不同結果可能是正常現象，請依預期配置比較。有多支 XInput 手把時，先拔掉其他手把，避免看錯槽位。

離開測試頁或正常關閉工具會恢復先前的串流狀態；若程式在測試中崩潰或被強制關閉，重新連接手把可重置暫時測試模式。

## 命令列

```powershell
# 讀取目前配置，不修改映射。
pwsh -NoProfile -File .\VaderMappings.ps1 -Mode Read

# C 映射為 A，不使用連發。
pwsh -NoProfile -File .\VaderMappings.ps1 -Mode Apply -Source C -Target A -TurboMode Off

# 按住 M1 時，每秒連發 RB 15 次。
pwsh -NoProfile -File .\VaderMappings.ps1 -Mode Apply -Source M1 -Target RB -TurboMode Hold -TurboRate 15 -TurboMaster On

# 停用 Z 的遊戲輸出，或恢復預設。
pwsh -NoProfile -File .\VaderMappings.ps1 -Mode Apply -Source Z -Target Disabled -TurboMode Off
pwsh -NoProfile -File .\VaderMappings.ps1 -Mode Apply -Source Z -Target Default

# 測試原始訊號與遊戲輸出三秒。
pwsh -NoProfile -File .\VaderMappings.ps1 -Mode Test -Seconds 3
```

`-TurboMode` 接受 `Keep`、`Off`、`Hold`、`Toggle`；`-TurboMaster` 接受 `Keep`、`On`、`Off`。輸出別名包含 `Default`、`Disabled`、`Keep`。

## 限制

目前沒有鍵盤／滑鼠綁定編輯，也未提供韌體刷寫、恢復原廠或改寫裝置識別碼的功能。巨集使用社群逆向協議；實測範圍以上方說明為準，不能視為所有按鍵與時間組合均已驗證。

避免同時使用其他改鍵程式，儲存時保持無線連線穩定，不要斷開手把。若還原失敗，程式會顯示本機備份位置；不能把寫入失敗當成已還原成功。

已測接收器轉送的韌體資訊回覆有檢查碼不符現象；工具只對已知型號及韌體的唯讀資訊封包提供相容處理。配置資料及寫入確認仍檢查校驗碼；無線讀取逾時可有限重試，寫入命令不自動重送。
